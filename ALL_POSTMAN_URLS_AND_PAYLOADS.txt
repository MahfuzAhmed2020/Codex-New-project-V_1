Demo Ordering API Postman URLs and Payloads
==========================================

Base URL
--------
http://localhost:8080

Frontend URLs
-------------
GET http://localhost:8080/index.html
GET http://localhost:8080/login.html
GET http://localhost:8080/forgot-password.html
GET http://localhost:8080/reset-password.html?token=<token>
GET http://localhost:8080/account-confirmed.html?token=<token>
GET http://localhost:8080/profile.html
GET http://localhost:8080/menu.html
GET http://localhost:8080/checkout.html
GET http://localhost:8080/confirmation.html
GET http://localhost:8080/order-history.html
GET http://localhost:8080/order-status.html?tracking=TRK-1-1

Auth APIs
---------
1. Register User
POST http://localhost:8080/api/auth/register
Payload:
{
  "firstName": "Ava",
  "lastName": "Johnson",
  "address": "123 Main St, New York, NY 10001",
  "zip": "10001",
  "phone": "555-123-4567",
  "email": "ava@example.com",
  "password": "secret123",
  "confirmPassword": "secret123"
}

2. Login User
POST http://localhost:8080/api/auth/login
Payload:
{
  "email": "ava@example.com",
  "password": "secret123"
}

3. Forgot Password
POST http://localhost:8080/api/auth/forgot-password
Payload:
{
  "email": "ava@example.com"
}

4. Reset Password
POST http://localhost:8080/api/auth/reset-password
Payload:
{
  "token": "paste-token-from-mailhog-link",
  "password": "newsecret123",
  "confirmPassword": "newsecret123"
}

5. Confirm Email
POST http://localhost:8080/api/auth/confirm-email
Payload:
{
  "token": "paste-token-from-mailhog-link"
}

POST http://localhost:8080/api/auth/logout
Payload:
No body required

User APIs
---------
6. Get All Users
GET http://localhost:8080/api/users

7. Get User By Id
GET http://localhost:8080/api/users/1

8. Update User Profile
PUT http://localhost:8080/api/users/1/profile
Payload:
{
  "firstName": "Ava",
  "lastName": "Johnson",
  "address": "500 Park Ave, New York, NY 10022",
  "zip": "10022",
  "phone": "555-999-1234",
  "email": "ava.updated@example.com"
}

9. Get User Orders
GET http://localhost:8080/api/users/1/orders

Menu APIs
---------
10. Get Menu
GET http://localhost:8080/api/menu

11. Get Menu Item By Id
GET http://localhost:8080/api/menu/1

12. Create Menu Item
POST http://localhost:8080/api/menu
Payload:
{
  "name": "Margherita Pizza",
  "description": "Classic pizza with tomato, mozzarella, and basil",
  "price": 13.75
}

13. Patch Menu Item
PATCH http://localhost:8080/api/menu/2
Payload:
{
  "price": 14.25,
  "description": "Creamy pasta with grilled chicken and parmesan"
}

14. Delete Menu Item
DELETE http://localhost:8080/api/menu/3

Cart APIs
---------
15. Get Cart
GET http://localhost:8080/api/users/1/cart

16. Add Item To Cart
POST http://localhost:8080/api/users/1/cart/items
Payload:
{
  "menuItemId": 1,
  "quantity": 2
}

17. Update Cart Item Quantity
PATCH http://localhost:8080/api/users/1/cart/items/1
Payload:
{
  "quantity": 3
}

18. Delete Cart Item
DELETE http://localhost:8080/api/users/1/cart/items/1

Checkout and Tracking APIs
--------------------------
19. Get Checkout Whitelist
GET http://localhost:8080/api/checkout/whitelist

20. Checkout User Cart
POST http://localhost:8080/api/users/1/checkout
Payload:
{
  "shippingAddress": "123 Main St, New York, NY 10001",
  "cardNumber": "4111111111111111"
}

21. Track Order Status API
GET http://localhost:8080/api/tracking/TRK-1-1

22. Track Order Status Browser URL
GET http://localhost:8080/order-status.html?tracking=TRK-1-1

Legacy Order APIs
-----------------
23. Get Orders
GET http://localhost:8080/api/orders

24. Get Order By Id
GET http://localhost:8080/api/orders/1

25. Create Legacy Order
POST http://localhost:8080/api/orders
Payload:
{
  "customerName": "Ava",
  "address": "123 Main St, New York, NY",
  "phoneNumber": "555-123-4567",
  "itemIds": [1, 3]
}

26. Patch Legacy Order
PATCH http://localhost:8080/api/orders/1
Payload:
{
  "customerName": "Ava Johnson",
  "address": "456 Oak Ave, Brooklyn, NY",
  "phoneNumber": "555-000-9999",
  "itemIds": [2]
}

27. Put Legacy Order
PUT http://localhost:8080/api/orders/1
Payload:
{
  "customerName": "Noah",
  "address": "789 Pine Rd, Queens, NY",
  "phoneNumber": "555-222-3333",
  "itemIds": [2, 3]
}

28. Delete Legacy Order
DELETE http://localhost:8080/api/orders/1

Notes
-----
- Replace token values with the real token copied from the MailHog email link.
- Replace tracking numbers with the tracking number returned by checkout.
- Use GET http://localhost:8080/api/menu first to see available menu item ids.
- Use GET http://localhost:8080/api/docs/urls to view the live endpoint list from the app.
